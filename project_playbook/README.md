# Project Playbook

This folder stores portable guidance for moving MaxBot 4 through three planned improvement stages.

It is not active runtime configuration. Active runtime files remain in:

- `app/`
- `business_profile/admin_profile.yaml`
- `app/data/services.yaml` as the legacy parity reference
- `.env`
- `tests/`
- `wiki/`
